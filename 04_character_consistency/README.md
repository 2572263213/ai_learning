# 同人文角色一致性检测

一个基于 RAG 与 Agent 的同人文角色一致性检测工具。用户选择角色、粘贴文本后，系统判断角色言行是否符合设定，并给出四层判断（合规 / 剧情驱动 / 角色复杂性 / 真OOC）和改写建议。

## 解决什么问题

同人文创作中，角色写崩（OOC）是作者最头疼的问题。但现有工具只做“静态比对”——拿角色设定和文本一对比，不符合就报 OOC。它们不懂剧情上下文，会把“角色因剧情需要而合理偏离”也误判成 OOC。

这个工具用混合检索、引用溯源和剧情上下文检测，把“行为异常”和“真OOC”区分开，把判断权交还给作者。

## 核心功能

- **混合检索**：向量检索 + BM25 关键词检索 + RRF 融合排序，兼顾语义和精确匹配
- **引用溯源**：检测报告里标明每条风险点来自角色设定的哪一条底线
- **用户自定义角色**：粘贴一段自由文本，LLM 自动解析成结构化角色档案，缺失字段用选择题补充
- **剧情上下文检测**：用户可填剧情背景，系统做四层判断：
  - 合规：言行符合设定
  - 剧情驱动：异常言行可用剧情解释
  - 角色复杂性：表面与内里的差异（策略性伪装、内心戏）
  - 真OOC：无法用任何理由解释，违反底线
- **改写建议**：根据判断类型生成修改后的文本，保留作者原有创作意图

## 技术栈

- Python 3.11
- LangChain（文本分割、向量库封装）
- ChromaDB（向量数据库）
- rank_bm25（BM25 关键词检索）
- sentence-transformers（bge-small-zh-v1.5 中文向量模型）
- Streamlit（前端界面）
- DeepSeek API（大模型推理）
- Pydantic（结构化输出校验）
